# 🍎 Catch the Fruit — Scratch Game

An interactive **arcade-style game built in Scratch** where the player controls a basket to catch falling fruits while avoiding misses.

This project demonstrates core game development concepts such as **event-driven programming, collision detection, variable tracking, and continuous game loops**.

---

## 🚀 Overview
- 🎮 Control a basket using arrow keys  
- 🍏 Catch falling fruits to increase score  
- ❌ Avoid missing fruits to prevent game over  
- ⚡ Simple mechanics with progressive challenge  

---

## 🎯 Features
- 🎮 **Keyboard Controls** — Smooth left/right movement  
- 🍎 **Collision Detection** — Real-time catch system  
- 🔢 **Score Tracking** — Increment on successful catch  
- ⚠️ **Miss Counter** — Tracks failed attempts  
- 🔄 **Infinite Gameplay Loop** — Continuous fruit falling  
- 🏆 **Win Condition** — Reach target score  
- 💀 **Game Over Condition** — Too many misses  

---

## 🧠 Concepts Demonstrated
- Event handling (`when green flag clicked`)  
- Game loops (`forever`)  
- Conditional logic (`if/else`)  
- Variables and state management  
- Sprite interaction (touch detection)  

---

## 🕹️ How to Play
1. Click **Green Flag** to start  
2. Use **← / → arrow keys** to move the basket  
3. Catch fruits to gain points  
4. Avoid missing fruits  
5. Reach the target score to win  

---

## 🏗️ Tech Stack
