# catch-fruit-scratch
An interactive arcade-style game built in Scratch where the player controls a basket to catch falling fruits while avoiding misses. The project demonstrates core game development concepts including event-driven programming, collision detection, variable tracking, and continuous game loops.

🎮 Project Description — Catch the Fruit (Scratch Game)


An interactive arcade-style game built in Scratch where the player controls a basket to catch falling fruits while avoiding misses. The project demonstrates core game development concepts including event-driven programming, collision detection, variable tracking, and continuous game loops.
---
---
🚀 Overview
Control a basket using arrow keys
Catch falling fruits to increase score 🍎
Avoid missing fruits to prevent game over ❌
Simple mechanics with progressive challenge
---
🎯 Features
🎮 Keyboard Controls — Smooth left/right movement
🍏 Collision Detection — Real-time catch system
🔢 Score Tracking — Increment on successful catch
⚠️ Miss Counter — Tracks failed attempts
🔄 Infinite Loop Gameplay — Continuous falling system
🏆 Win Condition — Score exceeds target
💀 Game Over Condition — Too many misses
---
🧠 Concepts Demonstrated
Event handling (when green flag clicked)
Game loops (forever)
Conditional logic (if/else)
Variables and state management
Sprite interaction (touch detection)
---
🕹️ How to Play

Start the game (Green Flag)
Use ← / → arrow keys to move the basket
Catch fruits to gain points
Avoid missing fruits
Reach the target score to win
---
🏗️ Tech Stack
🟣 Scratch 3.0 (Visual Programming)
---
📦 Project Structure
Stage → Background + variables
Basket Sprite → Player control logic
Fruit Sprite → Falling + collision system
